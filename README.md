# Tareeq

Hands-free Arabic learning while you drive. Site: https://tareeqapp.com · Contact: contact@tareeqapp.com

- `index.html`: landing page with full SEO metadata (Open Graph, X card, JSON-LD)
- `styleguide.html` + `DESIGN.md`: design system and brand style guide
- `css/`: design tokens and components

Preview locally: `python3 -m http.server 8000` then open http://localhost:8000
